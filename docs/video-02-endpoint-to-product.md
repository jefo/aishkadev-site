## Title

«От endpoint к продукту: как читать API с продуктовой оптикой»

## Hook

«Шесть методов. Ты умеешь их прочитать. Ты понимаешь, что каждый делает. И ты уже знаешь ответ: "Это API для генерации видео". Стоп. В этом "знаю" — вся проблема.»

## Description

Восемь мысленных переходов на примере Runway — от Feature Label до Thesis. Как перестать видеть список endpoints и начать видеть продукт: Feature Label → Capability, Capability → Workflow, Workflow → Buyer, Buyer → Product Shape, Product Shape → Constraints, Constraints → Economics, Economics → Thesis.

Урок: обозначение технологии ≠ понимание продуктовой ценности. Одиночный вызов API — не продукт. Workflow без buyer — пет-проект. Possible ≠ viable. Интерес ≠ потребность. Продукт — это ставка: «Я верю, что [конкретный buyer] готов платить за [конкретное изменение economics]».
