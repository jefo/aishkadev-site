# Hook Rubrics — Short-Form Canon (Raw)

**Дата:** 2026-08-07
**Статус:** Raw canon — рубрики для генерации hooks из одного Product Spec
**Роль:** Шаблон: один продукт → десятки hooks по рубрикам. Используется в Контуре 1 (Growth). Для каждого продукта — обход рубрик: какая формулировка останавливает разработчика.

---

| # | Рубрика | Пример hook (Ad Creative Factory) |
|---|---|---|
| 1 | **Экономика** | «Я заменил $500 видеокреатив за $0.75» |
| 2 | **Buyer** | «Я нашёл человека, который будет платить за Runway API» |
| 3 | **API → Product** | «Вот почему я не стал делать AI-видеогенератор» |
| 4 | **Developer angle** | «Я построил SaaS, используя чужой AI» |
| 5 | **Anti-startup** | «Этот стартап не написал ни одной AI-модели» |
| 6 | **Speed** | «Я сделал рекламную студию за один вечер» |
| 7 | **Arbitrage** | «Я продаю за $500 то, что AI делает за $0.75» |
| 8 | **Product thinking** | «Я не придумал технологию. Я придумал, кому она нужна.» |
| 9 | **Contrarian** | «Самая дорогая часть AI-стартапа — не AI» |
| 10 | **Challenge** | «Сколько денег можно сделать, если просто правильно упаковать Runway?» |

## Источник рубрик

Каждая рубрика — это срез одного слоя Product Anatomy, поданный как hook:
- Экономика → pricing, value unit
- Buyer → buyer persona, JTBD
- API → Product → capability → product transition
- Developer angle → «я как разработчик» (identity hook)
- Anti-startup → moat (workflow > endpoint)
- Speed → production mode
- Arbitrage → pricing vs альтернативы
- Product thinking → product judgment (central tension)
- Contrarian → competitive framing
- Challenge → investment judgment

## Правило производства

Один продукт → обход всех 10 рубрик → для каждой: hook-формулировка + 3-5 фактов из Product Spec + 1 визуальная система. Promise = буквально правда (Trust не сжигаем).
