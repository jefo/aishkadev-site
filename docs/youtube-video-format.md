# YouTube Video Format — выходной формат ролика

**Назначение:** упаковывает готовый материал (роут + проза) в ролик для YouTube. Ничего не переизобретает — роут задаёт почему, проза задаёт что говорить, формат задаёт как упаковать.

**Статус:** канон формата. Каждый ролик заполняется по этой структуре.

---

## Инвариант плотности

> **Хронометраж не меньше, чем сама проза. По информационной плотности проза идеальна — видео такое же.**

Каждая единица информации, которая есть в прозе, присутствует в ролике. Сжатие до «главного» запрещено: ролик не реферат, он переносит материал целиком в устную форму + визуальный слой.

Тайминги в артефакте не указываются — их решает director. Принцип плотности — контракт, не тайм-код.

---

## Структура

```
# YouTube Video — <сюжет>

## Title
<по Title Grammar + willingness-to-pay; «экономит N$ buyer'у на JTBD» — один из вариантов>

## Hook
<одно предложение — остановить скролл, первые секунды>

## Body
<beats = moves из роута; каждый beat — spoken + visual>

| Beat | Move | Spoken | Visual |
|---|---|---|---|
| 1 | <move> | <полный текст из прозы, без сжатия> | <каноническая визуальная дисциплина> |

## CTA
<подписка + следующий ролик — сериализация>

## Description
<публикационный минимум: что это, для кого, ключевые цифры>

## Production notes
- <Trust firewall: цифры только из Product Spec, ничего не додумано>
- <Epistemic commitment: KNOWN / INFERRED / VALIDATED по каждому claim>
- <Плотность: какая единица прозы перенесена куда>
```

---

## Правила

1. **Плотность ≥ прозы.** Каждый смысловой блок прозы имеет свой beat. Пустой beat или beat «в двух словах» — нарушение.
2. **Moves — из роута.** Не придумывать новые moves под ролик — брать структуру когнитивного трека.
3. **Spoken — из прозы.** Переформулировка в устную речь допустима, потеря информации — нет.
4. **Visual — каноническая дисциплина** (semantic-native-representation): Customer Profile, Process Map, Capability Map, Opportunity Solution Tree, VPC, Before/After Economics, System Diagram. Не ad hoc.
5. **Trust firewall.** Цифры только из Product Spec. Ничего не додумано, никаких «около $500» без источника.
6. **Epistemic commitment.** Claim не превышает уровень валидации: KNOWN (design price) → утверждение, INFERRED (предсказание) → вопросительная форма, VALIDATED (реальный платёж) → утверждение.
7. **Сериализация.** CTA открывает следующий ролик — каждый ролик это episode, не standalone.
8. **Тайминги — за скобками.** Решает director. В артефакте нет секунд.
